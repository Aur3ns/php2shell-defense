# Zeek integration: experimental scaffold

The script at `__load__.zeek` is a **minimal Zeek package scaffold**, not yet an effective signature or production notice pipeline. Zeek's HTTP metadata alone cannot prove any PHP2Shell exploit.

For meaningful detection, correlate an authorized HTTP body analyzer with bounded multipart counts, session characteristics and host evidence. Work must respect inspection limits, encrypted traffic visibility, and privacy. Do not describe this scaffold as a complete detection.
